AI 帮你做了看板、报告、网站、PR，过一周就全埋在长长的会话里了。第一次打开，Sesame 会读一遍你已有的 Claude Code 和 Codex 记录，数出你自己的数字。打开的是产物本身，不是当时那段对话。 Your AI builds dashboards, reports, sites and pull requests. A week later they are buried in long chats. On first launch Sesame reads your existing Claude Code and Codex history and counts your own number. What opens is the artifact itself, not the chat it came from.

页面里的数字和产物名都是演示数据。Numbers and titles on this page are demo data.

01

按住热键，直接说Hold the hot key and say it

轻按打开面板打字；按住说，松开就发送。说「打开上周那个交易大盘」，打开的是大盘本身。Tap it to type; hold it to talk, let go to send. "Open last week's trading dashboard" opens the dashboard itself.

⌥⇧Space默认热键，可在设置里换成by default; switch to⌘Spacein Settings

02

边打字边出结果Type, and it's already there

打第一个字就有结果。↑ ↓ 选，↵ 打开。本地对不上时，按 ↵ 让 Sesame 去全部记录里找。Results show up with the first letters. ↑ ↓ to pick, ↵ to open. If no local match fits, ↵ lets Sesame search your full history.

03

不止一个？挑一个More than one match? Pick one

名字都对得上的不止一个时，给你一个短列表，不瞎猜；一个都对不上就直接说没找到，不拿凑数的顶上。When several names fit, you get a short list instead of a guess; when none fits, it says so instead of offering filler.

分享你的数字Share your number

开场页的「分享」把你的数字做成一张 1200×675 的图，存进「下载」并复制好，直接贴进帖子。图上只有计数，没有任何标题、路径或名字。Share on the first-run panel turns your number into a 1200×675 image, saves it to Downloads and copies it, ready to paste into a post. Only counts are on it: no titles, paths or names.

在 Claude Code 里，
直接问Ask right inside
Claude Code

Sesame 也能作为插件跑在 Claude Code 里。在任何会话里直接说要找什么，Claude 会去你的产物库里查，再在你的 Mac 上打开。App 装不装都行：没装时插件自己从 Claude Code 和 Codex 的历史里建同样的本地索引；装了就和 App 共用一份索引。Sesame also runs inside Claude Code as a plugin. Ask in plain words in any session and Claude looks it up in your library, then opens it on your Mac. The app is optional: without it, the plugin builds the same local index from your Claude Code and Codex history; with it, both share one index.

$ claude plugin marketplace add qiwei66/sesame && claude plugin install sesame@sesame

三个工具：search_artifacts、open_artifact、artifact_stats。其它 MCP 客户端用 va mcp 跑同一个服务，见Three tools: search_artifacts, open_artifact and artifact_stats. Any other MCP client can run the same server with va mcp; see docs/mcp.md

上周那个看板在哪Where is the trading dashboard from last week?

search_artifacts → open_artifact

找到了：Trading Dashboard，本机服务 http://127.0.0.1:8787，上周末（09-27）最后用过，已经在浏览器里打开。Found it: your Trading Dashboard is a local web service at http://127.0.0.1:8787, last seen on September 27. It's opening in your browser now.

把我昨天做的报告打开Open the report I made yesterday

search_artifacts → open_artifact

找到了你昨天的报告 Q3 sales report（Markdown 文件），已为你打开。Found yesterday's report, Q3 sales report (a Markdown file), and opened it.

你的记录，留在你的 Mac 上Your history stays on your Mac

索引只在本机Index on your Mac

索引存在 ~/Library/Application Support/Sesame，不会上传。The index lives in ~/Library/Application Support/Sesame and is never uploaded.

只读两个目录Reads two folders

只读 ~/.claude/projects 和 ~/.codex/sessions，从不往里写。Only ~/.claude/projects and ~/.codex/sessions, and it never writes to them.

模型可配可不配A model is optional

配了的话，发出去的只有你说的那句话、已装 App 的名字，以及本地拿不准时各候选的类型、标题和几个关键词；完整链接、文件路径、剪贴板都不发。If you set one up, it gets your sentence, your app names and, when local search can't decide, each candidate's type, title and a few keywords. Never full links, file paths or your clipboard.

开源，MITOpen source, MIT

每一行代码都在 GitHub 上，可以自己读、自己编译。Every line is on GitHub. Read it, build it yourself.

装上就有Useful the moment you install it

Homebrew 会装好 Node.js，在你的 Mac 上从源码编译 App 并 ad-hoc 签名，不弹 Gatekeeper 警告，也不需要苹果开发者账号。Homebrew brings Node.js, builds the app from source on your Mac and ad-hoc signs it: no Gatekeeper warning, no Apple Developer account needed.

需要 macOS 13 或更新版本。热键默认 ⌥⇧Space，可在「设置 → 热键」里换成 ⌘Space。Needs macOS 13 or later. The hot key is ⌥⇧Space; switch to ⌘Space in Settings › Hot key.
